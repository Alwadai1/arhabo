# أرحبو · Arhabo

**حكايا القرى التراثية · Heritage Villages of Saudi Arabia**

لعبة فيديو تفاعلية ثلاثية الأبعاد تعمل في المتصفح، تأخذ اللاعب في رحلة إلى القرى التراثية في جنوب المملكة العربية السعودية. المرحلة الأولى: **بلدة ظهران الجنوب التراثية** ومهمة «ضيافة أبي ظافر».

An interactive 3D browser game exploring the heritage villages of Asir and Dhahran Al-Janoub, Saudi Arabia. First chapter: the Dhahran Al-Janoub heritage town.

## التشغيل · Play
- على الإنترنت: افتح رابط GitHub Pages للمستودع.
- محلياً: نزّل الملفات وافتح `index.html` في Chrome أو Edge (يجب أن يكون `three.min.js` بجانبه).

## التحكم · Controls
- الحركة: W A S D أو الأسهم، وعصا التحكم على الجوال.
- الكاميرا: السحب بالفأرة أو بالإصبع.
- التحدث: E أو زر «تحدّث». الجري: Shift. المنظر الجوي: M.

## نسخة تجريبية · Beta
المعلومات والأسماء والأشكال تُراجَع مع أهالي البلدة. ملاحظاتكم ترحَّب.
